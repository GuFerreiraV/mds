> O comando `mount` é utilizado para montar um dispositivo na hierarquia do sistema de arquivos do Linux manualmente. Para desmontar, basta usar o comando `unmount`

### Hierarquia 

- O sistema de arquivos do Linux é hierárquico e admite que diversos dispositivos sejam mapeados a partir da raiz do sistema `/` (**root**).
- Dessa forma, DVD, pendrives etc., poderão ser utilizados de forma bastante simples, e o usuário enxergará estes dispositivos como um [**diretório na estrutura do Linux**](/2b5e4af651cd8096a35eca51195526ed)[.](/2b5e4af651cd8096a35eca51195526ed)
- O Fylesystem Hierarchy Standard separou dois diretórios que servirão como hospedeiros para os dispositivos chamados de pontos de montagem:
    - /mnt → Para sistemas de arquivos montados momentanemente, como discos rígidos.
    - /media → Para mídia removível, como CD-ROMs, pendrive etc.
