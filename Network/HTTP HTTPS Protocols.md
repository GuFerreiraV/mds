## HTTP: Hypertext Transfer Protocol 
Protocolo responsável por transferir daddos entre cliente e um **servidor**. Por exemplo, quando visitamos um website, nós **(cliente)** enviamos uma requisição http para o **servidor**, perguntando sobre a página ou outros recursos que solicitamos. O **servidor** envia a resposta de volta para nós **(cliente)**.

---

## HTTPS: Hypertext Transfer Protocol Secure
Este protocolo adiciona uma camada à mais de segurança. Durante o tráfego de informações entre **cliente** e o **servidor** utlizamos a encriptação **SSL/TLS (Secure Sockets Layer/Transport Layer Security)**, ajudando a proteger informações sensíveis, como credenciais de login, infomações de pagamentos e entre outros dados pessoais. 

---

## SSL/TLS 

> Secure Sockets Layer

Protocolo de comunicação/conjunto de regras, que cria uma conexão segura entre dois dispositivos ou duas aplicações em uma rede. O SSL é a tecnologia que suas aplicações ou navegadores podem ter usado para criar um canal de comunicação seguro e criptografado em qualquer rede. No entanto, o SSL é uma tecnologia mais antiga que contém algumas falhas de segurança. O **Transport Layer Security (TLS) é a versão atualizada do SSL que corrige as vulnerabilidades existentes do SSL**. O TLS autentica com mais eficiência e continua a oferecer suporte a canais de comunicação criptografados.
